### Hola, soy Kevin Berthet 👋

**Desarrollador full stack · Creador de Void · Argentina 🇦🇷**

Construyo **aplicaciones web y móviles** que combinan arquitectura, funcionalidad y diseño. Me interesa trabajar en todo el recorrido de un producto: desde sus modelos de datos, reglas de negocio y APIs hasta una interfaz responsive que se disfrute usar.

Con **Void** desarrollo sistemas, herramientas comerciales y experiencias digitales. Mis repositorios muestran tanto proyectos académicos como casos reales de desarrollo.

> **Mi enfoque:** ingeniería clara, buenas experiencias y atención a los detalles.

## Proyectos seleccionados

### 🏥 [Clínica · Sistema de gestión de turnos](https://github.com/Kingdoms27/TP-CLINICA-DDAW)

**Aplicación full stack · Angular · NestJS · PostgreSQL · TypeORM**

Sistema de reservas para **pacientes, médicos y administradores**, con autenticación JWT, permisos por rol, validaciones, control de horarios duplicados, historial y gestión de consultas. Proyecto académico del Grupo K.

[**Explorar código y documentación ↗**](https://github.com/Kingdoms27/TP-CLINICA-DDAW)

### 📍 [Mi Ciudad Colón · Guía turística móvil](https://github.com/Kingdoms27/Mi-Ciudad-MOBILE-)

**Aplicación móvil · React Native · Expo · TypeScript · SQLite**

Guía para descubrir lugares y eventos con **mapa, ubicación, favoritos, audioguías, visitas por QR y soporte offline**, orientada a Android y iOS. Proyecto académico de Desarrollo para Móviles.

[**Explorar código y documentación ↗**](https://github.com/Kingdoms27/Mi-Ciudad-MOBILE-)

### 🧩 [Clínica OOWS · Modelado y desarrollo web](https://github.com/Kingdoms27/TP-CLINICA-OOWS)

**Arquitectura web · Angular · NestJS · OOWS · TypeORM**

Implementación de un sistema de turnos siguiendo los modelos **conceptual, navegacional y de presentación** de la metodología OOWS. Incluye navegación por roles, API y pruebas.

[**Explorar código y modelos ↗**](https://github.com/Kingdoms27/TP-CLINICA-OOWS)
